# تجربة العمل تحت الضغط | Pressure Game

مشروع لعبة تفاعلية تهدف إلى اختبار التركيز والانتباه والذاكرة أثناء أداء المهام تحت الضغط.

## فكرة المشروع
تتكون اللعبة من مستويين رئيسيين:

- **المستوى الأول:** تحدي البحث عن الأرقام العشوائية خلال 50 ثانية.
- **المستوى الثاني:** تحدي التعرف على الأشكال خلال 50 ثانية، ثم الاستماع إلى ثلاثة أرقام وسط أصوات مشتتة وتذكرها بالترتيب الصحيح.

وفي نهاية اللعبة، تظهر أسئلة للتفكير في التجربة ورسالة توعوية حول تأثير تعدد المهام على التركيز والأداء.

## التقنيات المستخدمة

- CSS
- JavaScript
